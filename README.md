# My QuizDock quizzes

Quizzes made with [QuizDock](https://github.com/quizdock/quiz-dock), shared through the QuizDock community store.

## Publish a quiz

1. In QuizDock, open the quiz and choose **Export for publication**. Keep the `.quizdock.zip` file as it is.
2. Here, open the **quizzes** folder, click **Add file → Upload files**, drop the file, then **Commit changes**.

To update a quiz, upload its new export, and delete the old file if its name differs. To remove it, delete its file.

The full guide: [publish your quizzes](https://github.com/quizdock/quiz-store/blob/main/CONTRIBUTING.md).
